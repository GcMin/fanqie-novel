# 第49章详细章纲：掉下来的门牌

## Planner

### 本章目标

以一张真正需要夜间处置的普通门楼牌坠落风险工单开启第三卷。先把人员安全和责任联动做完，再通过同一院落“旧号仍被居民使用 / 新号已成为现行标准地址”的正常沿革记录，建立正式地址正常变更的控制样本。章节结束时，周衡应当知道正常门楼牌变更会留下哪些可核字段，并获得下一章可沿来源文书/沿革索引继续理解正式地址体系的合法入口。

### POV
周衡近距离第三人称。

### 开场状态
Day 3 23:27，第二卷阶段核验刚提交。周衡、梁策、夏宁仍在临江市夜间综合服务中心第三夜班，下一张普通工单正在加载。BK-JBS-160114-03 / S2-07仍待正常盘点，不在本章强行出结果。

### 角色想得到什么
- 周衡：先把新工单的坠落风险处置掉，再弄清为什么来电人口述地址与系统现行地址不同。
- 夏宁：把旧称、新标准地址、责任单位和原始来话分开记录，避免为了派单擅自把来电地址改掉。
- 梁策：确认两人能把“正常地址沿革”当对照，而不是一看到旧门牌就往永安里上套。

### 阻碍 / 冲突
来电人报“花枝巷17号”，现行标准地址服务却返回同一坐标院落“槐北路112号附1”。来电人坚持墙上确实有“花枝巷17号”的旧搪瓷牌，而且已经松动，下面是夜间仍有人进出的院门。地址不一致首先影响责任派发和现场定位，但它可能完全是正常历史改号，不能被主线情绪异常化。

### 关键 beats

1. 23:27新工单进入：老城区一块门牌松动，来电人担心掉下来砸到人。周衡先核位置、悬挂高度、下方通行和是否能安全绕开，要求来电人不要自行爬梯拆牌，并先让院内人员避开正下方。
2. 夏宁发现来电人报“花枝巷17号”，现行标准地址返回“槐北路112号附1”，但坐标和院落轮廓一致。她保留原述地址，同时按现行地址派给属地街道夜间值守/门楼牌维护协作，不擅自把原始来话改成新号。
3. 现行地址服务中的历史沿革卡给出普通旧号→新号映射：2018年旧城巷道并址整编后，“花枝巷17号”调整为“槐北路112号附1”，有生效时间、变更原因和来源通知文号。三人只把这些字段当作当前派单辅助信息。
4. 现场维护人员到达后确认：现行蓝色标准门牌完整固定在院门右侧；松动的是侧墙上多年未拆的旧白底搪瓷牌“花枝巷17号”。旧牌物理存在，但已不是现行有效门牌。维护人员先做下方隔离，再按职责拆下松动旧牌并留存处置记录。
5. 来电人回访时自然说明附近老住户仍习惯叫“花枝巷十七号”，快递和熟人也听得懂；这与现行标准地址“槐北路112号附1”并不冲突。周衡第一次获得一个完整、正常、没有异常机制参与的“口头旧称 / 旧实体牌 / 新标准地址 / 正式变更文书”四层对照。
6. 工单闭环后，周衡把正常沿革卡的字段抄进本子：旧号、新号、生效时间、变更原因、来源文书、当前有效状态。梁策明确提醒：一个正常样本只能说明正常流程可能留下什么，不能证明永安里也经历过同样变更。
7. 夏宁从该正常案例的来源页看到历史门楼牌资料存在“沿革索引”，夜间权限只能看到目录和文书编号，不能打开更早底册。三人决定下一步只沿索引规则和来源文书理解检索方法，不拿“永安里6栋201”直接全文搜索。

### 本章新增信息
- 临江市现行标准地址服务允许保留历史门楼牌沿革卡，正常变更记录可同时保存旧号、新号、生效时间、变更原因、来源文书和当前有效状态。
- 实体旧门牌可以因为普通管理遗留继续挂在建筑上，即使正式地址早已变更；实体残留与当前有效地址是不同事实。
- 历史门楼牌资料存在按变更批次/来源文书组织的沿革索引，但当前夜班权限只可看到目录级入口。

Day 4约00:10。门牌坠落风险处置闭环，花枝巷17号→槐北路112号附1的正常沿革链已核清。周衡记录“正常改号应该留下什么”；夏宁只取得历史门楼牌沿革索引的目录入口。第50章再理解旧号/新号登记方式和来源文书，不直接搜索永安里。
