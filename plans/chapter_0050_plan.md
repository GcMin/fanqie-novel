# 第50章详细章纲：旧号新号

## Planner

### 本章目标

沿第49章已经闭环的正常案例“花枝巷17号 → 槐北路112号附1”，只使用其来源文书与历史门楼牌沿革索引，弄清临江市正常旧号/新号变更在目录中如何定位、如何回到现行地址卡，并用东桥片区另一条普通变更记录做交叉验证。章节结束时，三人应得到一套可重复的正常检索路径，并明确“已有来源文书”和“只有历史位置范围”是两种不同入口，为第51章按旧城图幅申请历史索引做准备。

### POV
周衡近距离第三人称。

### 开场状态
Day 4约00:10。周衡、梁策、夏宁仍在临江市夜间综合服务中心第三夜班。第49章门牌坠落工单已经闭环；现行地址沿革卡确认花枝巷17号于2018-06-18调整为槐北路112号附1，来源文书为“东桥片区门楼牌调整通知，2018年第27批”。三人只取得历史门楼牌沿革索引的目录级入口，夜间账号不能打开历史底册全文。BK-JBS-160114-03 / S2-07实物盘点仍待正常权限结果。Day 3 23:08商业街井盖松动普通工单最终现场结果仍未记录，本章不得倒写为已闭环。

### 角色想得到什么
- 周衡：把“正常地址变更会留下记录”进一步变成真正可操作的查找顺序，而不是再抄一遍第49章六项字段。
- 夏宁：确认目录索引如何从行政区片、批次、来源文书定位到具体变更条目，并验证目录与现行地址卡之间的对应关系。
- 梁策：防止二人把一套正常索引规则直接套成永安里答案；要求每一步都能说清楚“用什么条件找到下一层”。

### 阻碍 / 冲突
夜间联动权限只能看目录和现行基础沿革，不能打开历史底册正文；目录本身也不是按“想找什么地名”设计的全文搜索器。若只凭第49章已知结果反查，容易误以为所有历史地址都能直接用旧名搜到。必须通过第二条普通记录验证索引路径，区分“已知来源文书”与“只知道历史位置/年代”两类情况。

### 关键 beats

1. 00:12左右，夏宁从第49章地址卡上的来源文书“2018年第27批”进入沿革索引，不输入任何旧地名。目录先定位“东桥片区 / 2018年 / 第27批”，显示对应变更登记册的页段、条目范围及来源文书，而非直接开放底册全文。
2. 三人用花枝巷案例做回查：索引中的一条记录能把“旧号记录 → 现号记录”指向同一院落，并与现行地址卡的生效日期、来源文书一致。周衡注意到真正稳定的锚点是片区、批次、来源文书和条目位置，不是墙上是否还留旧牌。
3. 为避免只拿已知答案验证已知答案，夏宁从同一第27批目录中随机选择另一条普通变更，不沿花枝巷名称扩搜。该条为“纸坊巷8号 → 槐北路108号”，同样因旧城支巷并址整编生效。她再从现行“槐北路108号”地址卡反向核，来源文书和生效日期与索引一致，证明目录路径可在第二个普通样本上重复。
4. 第二条案例出现一个有用差异：现行地址卡没有任何“旧实体牌是否还存在”的字段，目录也不记录居民平时怎么称呼。三人据此把索引用途压回正式地址变更本身，不让它承担口头地名或实物遗留信息。
5. 周衡尝试总结查找顺序，梁策要求他说“如果你没有来源文书怎么办”。夏宁查看目录说明：较新的资料可按行政区片 + 年度/批次进入；更早、批次信息不完整的历史资料，需要先用行政区片 + 历史图幅/大致年代缩小索引范围，再由目录返回候选来源文书或保管卷册。夜间账号仍只能申请目录范围，不能直接看底册。
6. 周衡把方法写成两条：有来源文书时，沿文书→批次→条目→现行地址卡交叉核；无来源文书时，先用历史位置范围/图幅+年代找候选批次，再申请对应来源，不以目标地名全文捕鱼。
7. 章尾，夏宁调出此前2010公共导向底图已保存的旧B口图幅号，但只停在“申请条件”页面，没有提交结果查询、没有输入“永安里”。第51章才按该图幅与年代申请目标区片门楼牌沿革索引目录。

### 本章新增信息
- 临江市历史门楼牌沿革索引的正常使用路径可以从“行政区片 → 年度/变更批次 → 来源文书 → 条目位置”定位；索引目录不等于底册全文。
- 同一普通变更批次中的第二条记录“纸坊巷8号 → 槐北路108号”可由现行地址卡独立反向核对来源文书和生效时间，证明第49章路径不是单条特例。
- 对缺少来源文书的更早资料，目录说明允许先以行政区片、历史图幅和大致年代缩小候选范围，再申请对应批次/卷册；这成为第51章合法入口。
- 正式地址沿革索引不记录居民口头叫法，也不负责证明旧实体牌是否残留。

### 状态变化
