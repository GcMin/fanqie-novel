# 第47章详细章纲：指向哪里

## Planner

- **本章目标**：沿既有2011旧槐荫路导向图与2016导向牌的资料来源继续向上核，确认“永安里”作为公共导向目的地究竟依据什么被写进轨道导向系统；同时把公共导向地名与正式标准地址/门楼牌体系明确拆开，既推进F003，也保留“永安里6栋201”独立历史证明缺口。
- **POV**：周衡近距离第三人称。
- **开场状态**：Day 3约22:09，瑞景苑4栋普通高区停水工单刚完成；第三夜班继续。`BK-JBS-160114-03 / S2-07`实物盘点仍处于正常盘点队列，没有结果。本章不催样本间、不追旧站务亭人员。
- **角色目标**：周衡希望知道“站里为什么会把永安里当成一个可以给乘客指路的地方”；夏宁负责从既有2011导向图的编制依据/源数据编号反查公共导向资料，不按“永安里”关键词泛搜；梁策负责压住“有地名=有正式地址”的过度推断。
- **制度/证据边界**：轨道导向系统、城市公共导向/地名服务图层、标准地址/门楼牌体系是不同业务层。公共导向允许使用约定俗成居民地、市场、公园等目的地名称；能证明“人们当时按这个名字找方向”，不能自动证明某栋某室曾在正式地址库登记。

## 关键 beats

1. 22:15后普通值守短暂平稳。夏宁不再看S2-07盘点，而是回到第20章已经保存的2011旧槐荫路导向图原始核验页，查看图纸的“编制依据/数据来源”栏，找到一条市级公共导向底图来源编号：`GGDX-2010-11`（临江市旧城片区公共导向底图，2010年11月版）。
2. 中心历史资料接口能按来源编号调阅该公共导向底图的只读快照和数据字典；三人只按`GGDX-2010-11`与旧B口所在图幅进入，不使用“永安里”做全库关键词检索。
3. 旧B口对应图幅中存在一个公共导向点，编号`YD-073`，名称“永安里”，类别为“居民地（沿用名）”，位置说明落在槐荫路旧B口外的旧城居民区方向；状态字段为“可用于公共导向”。这是一份轨道体系之外的正常公共信息来源。
4. 同一底图的数据字典明确：公共导向点可以采用历史沿用名、约定俗成居民地名、市场/公园等公众熟知目的地；该图层不生成门楼牌号码，也不替代标准地址基础库。梁策要求先把这条规则写进核验记录，再看“永安里”本身。
5. 三人回看2011轨道B口导向图的审核附件/引用字段，确认其“永安里”条目引用的正是`YD-073`，所以2011旧图与2016实体导向牌不再只是两份互相抄写的轨道材料，而能追到一个独立的市级公共导向来源。
6. 为避免把“公共导向存在”偷换成“正式地址存在”，夏宁再按`YD-073`所在历史图幅/空间范围进入同期标准地址快照，只核该范围的对象类型与名称。当前可见的2011标准地址快照中，没有以“永安里”为标准地址对象的门楼牌/建筑条目；但该结果只限当前快照和可见范围，不写成“永安里从未有正式地址”。
7. 周衡把证据分成两列：公共导向层——2010公共导向底图`YD-073`、2011轨道旧图、2016实体牌；正式地址层——当前仍缺“永安里6栋201”独立门楼牌/住户链。F003因此向前推进一层，但M003继续锁住。
8. 梁策提醒：公共导向资料证明的是“那时候有人会按这个名字找路”，不是“6栋201已经被行政系统承认”。周衡不再试图给这层证据加更大的名字。
9. 章尾夏宁把`YD-073 / GGDX-2010-11`加入阶段证据表；S2-07仍无实物盘点结果。第48章将把804照片、2011轨道导向图、2016实体牌/拆移链、2010公共导向底图与正式地址缺口放在同一张来源表里做第二卷阶段收束，而不是继续无限向外查库。

## Meaningful State Change

- “永安里”从轨道系统内部的2011旧图 + 2016实体导向牌，推进为可追溯到轨道体系外、市级公共导向底图`GGDX-2010-11`中的独立公共导向点`YD-073`，证明其历史公共地名/目的地使用不是单一轨道资料自循环。
- 同时首次明确建立“公共导向地名存在”与“正式门楼牌/标准地址存在”两层证据边界；当前2011同期标准地址快照仍没有补上“永安里6栋201”的正式地址链。
- ARC-004获得可在第48章收束的阶段结构：公共导向层证据已经成链，正式地址层仍缺口明确，S2-07实物核验继续按正常权限等待。
