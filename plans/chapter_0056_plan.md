# 第56章详细章纲：迁出批次里的对象

## 本章目标
沿第55章取得的`DQLP-2010-04-B3`迁出对象清册正常调阅结果，先确认“迁出”在门楼牌业务中的真实含义和清册实际对象层级，再把“永安里历史登记片区”推进到一个可以继续核建筑地址/居住登记关联的独立业务入口；不得由清册标题、组号或项目号直接补出“永安里6栋201”。

## POV
第三人称限知，固定周衡视角。

## 开场状态
Day 4约21:27，周衡、梁策、夏宁仍在第四次夜班。第55章刚确认129页“历史登记片区=永安里”，21:24已提交`DQLP-2010-04-B3`最小范围只读申请；该申请仍待东桥区资料室按开放范围人工核验。`BK-JBS-160114-03 / S2-07`仍为待实物确认。

## 角色想得到什么
- 周衡：确认B3究竟记录片区、建筑、门牌还是居民，不让“迁出”两个字替自己下结论。
- 夏宁：只按既有申请和授权范围读取，保留字段、上下文、来源与后续索引，不扩大到姓名或目标住址全文搜索。
- 梁策：继续卡住证据尺度，尤其防止把业务“迁出”误读成居民物理迁走，或把登记对象编号当成门牌号。

## 阻碍 / 冲突
- B3申请需要资料室工作时段人工核验，夜间不能即时得到正文。
- “迁出对象清册”这一名称天然容易让人联想到居民搬迁，但门楼牌业务中的“迁出”可能只指登记对象从当前底册转入后续核对专卷。
- 即使清册进入建筑对象层，也不代表具体“6栋201”出现；居民登记又属于另一业务层和更严格权限。

## 关键 beats
1. 21:27后B3仍为待人工核验，三人回到普通夜班队列；正文不流水账复述整夜，只通过少量时间跳转表明夜班正常继续。到Day 5约07:30，S2-07仍无新结果。
2. 东桥区早班返回B3核验：只开放与129页对应的清册片段、表头和前后正常样本。清册页首说明“迁出”是门楼牌登记对象从本批底册转入后续地址核对专卷，不等同于人口迁移或居民搬离。
3. 前后普通样本显示B3按“历史登记片区 / 组号 / 对象类别 / 对象数量 / 处理方式 / 承接索引”登记，不直接列住户姓名。永安里对应行的对象类别为“建筑门楼牌登记对象”，处理方式为“转住址核对专卷”，承接索引为`DQ-DZHD-2010-17`；当前开放字段不出现6栋、201或住户姓名。
4. 周衡一度追问“迁出是不是人搬走”，夏宁用表头说明与邻行样本压回业务含义；梁策再问“对象号是不是门牌”，周衡明确否定，固定“组号/对象编号≠门牌号/栋号”的边界。
5. 三人只查看`DQ-DZHD-2010-17`的目录元数据。目录显示该专卷含“建筑地址对应表”“门楼牌来源核对表”“居住登记关联索引（目录级）”及“来源核验附件目录”等类别；目录能证明后续存在建筑/居住登记的正常业务入口，但不开放居民姓名、具体住址正文。
6. 夏宁仅提交`DQ-DZHD-2010-17`的建筑地址对应表与来源核验附件目录只读申请，不申请居民姓名层、不输入周衡/6栋201。章末状态停在申请受理，下一章才能看附件目录是否自然接回夜间中心旧处置记录。
