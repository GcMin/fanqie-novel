# 第51章详细章纲：图幅索引

## Planner

### 本章目标

沿第50章已经保存但未提交的“旧B口行政区片 + 历史图幅”申请草稿，先用已有历史节点确定合理年代范围，再提交门楼牌沿革目录范围申请。章节结束时只取得目标区片在该年代内的候选卷册/批次及其目录覆盖状态，形成下一章可核的具体纸档/数字化缺口；不得用“永安里”或“永安里6栋201”作无来源全文搜索，也不得把目录缺项扩大成历史不存在。

### POV
周衡近距离第三人称。

### 开场状态
Day 4约00:35。周衡、梁策、夏宁仍在临江市夜间综合服务中心第三夜班。第50章已用花枝巷、纸坊巷两条普通案例确认门楼牌沿革索引的正常定位方法。旧B口申请草稿只填了行政区片和2010公共导向底图历史图幅，时间范围与申请理由为空，提交按钮不可用。BK-JBS-160114-03 / S2-07实物盘点仍待正常权限结果。Day 3 23:08商业街井盖工单最终现场结果仍未记录。

### 角色想得到什么
- 周衡：用已知事实给申请划出一个“不靠目标答案反推”的年代范围，并知道下一步究竟该去哪个卷册/批次找正式地址资料。
- 夏宁：让申请条件、理由、权限和返回结果都可追溯；目录返回什么就记录什么，不把缺页或未数字化自动写成异常。
- 梁策：防止二人为了缩小范围，把2010公共导向证据偷换成“2010年正式地址一定存在”；要求每个边界都来自已有独立资料。

### 阻碍 / 冲突
他们知道2010公共导向底图、2011轨道引用和2008—2012旧站历史节点，但这些只能用于确定“值得查的时间窗口”，不能证明正式地址层在同一时期必有对应条目。夜间权限仍只返回目录级候选，不开放底册全文；返回范围可能存在数字化不完整，且这种缺口首先应视为普通档案状态。

### 关键 beats

1. 00:38左右，周衡和夏宁重新打开未提交申请。两人不用目标地名，先讨论时间范围。周衡提出以2008年槐荫路仍为二号线终点、2010公共导向底图、2011轨道引用、2012线路延伸四个已知节点，把首轮范围定为2008—2012；梁策要求在理由中写成“覆盖已知历史资料形成期”，而不是“永安里存在期”。
2. 夏宁填写申请理由：核对旧B口历史图幅覆盖区在2008—2012年的门楼牌沿革目录，用于历史服务记录地址归属核验。历史图幅仅作位置范围条件，不作为正式地址证明；申请中不出现“永安里”或“6栋201”。
3. 00:44提交目录范围申请。系统只返回受限的目录元数据，不开放底册影像。候选范围包括2008—2009年度旧城门楼牌维护索引、2010—2011旧城门楼牌整编索引、2012门楼牌调整补录索引等三组，均覆盖申请图幅或其相邻边界。
4. 三人按时间重合度和来源类型，不按地名选择2010—2011这组作为下一层优先候选。目录显示它对应一册连续登记册以及若干来源批次，其中“2010年旧城门楼牌整编第4批”与“2011年第2批”覆盖申请图幅；夜间账号只能看到卷册号、纸质页段、数字化页序和保管状态。
5. 周衡发现2010年第4批对应纸质页段连续，但数字化页序少一页：纸册登记为117—146页，当前可见影像为117—128、130—146，129页状态栏只写“纸档页号存在 / 数字化影像未挂接，保管状态待核”。他没有把“缺129页”写成被删，只记录为“数字化缺页，纸档状态未确认”。
6. 当前可见目录条目没有提供足以判断“永安里6栋201”的门牌级正文；即使某些摘要中未见目标名称，也只能限于当前可见索引字段，不能作为正式地址层阴性结论。梁策要求先把129页为什么没挂接弄清楚，再决定是否继续看该批次。
7. 章尾，夏宁提交一个只针对“2010年第4批 / 登记册129页”的保管状态核验请求，问题限定为：纸页是否存在、是否未数字化、是否移交/重装订/损毁，以及当前可调阅位置。第52章《缺的一页》只处理这一普通档案缺口，不先推异常删除。
