# 全书压缩摘要

用于让 AI 在不重读全部历史正文的情况下快速掌握已经发生的主线。

## 更新规则
- 每章结束后可补充必要事实。
- 至少每 10 章重新压缩整理一次。
- 只保留对未来仍有影响的信息，不写流水账。

## 当前摘要（第60章后）

28岁的周衡在物业工程岗位调整后，以外包新人身份进入临江市夜间综合服务中心。第一晚00:17，他接到“青梧苑13栋704”生活噪音工单，但地图、物业、门岗、普通住户和现行接管资料都只承认青梧苑有12栋。资深外勤梁策坚持保留原地址并按普通工单流程处置，调度员夏宁负责保存原始热线、完整页面、来源时间和不同媒介副本。三人的长期工作方法逐步固定为：先处理现实安全与正常业务，再按来源、时间、业务用途和授权边界保存证据；任何单一异常记录都不能直接命名机制。

第一夜，12栋后停车区在约01:03出现一条固定监控看不到、手机却能拍到的道路，周衡和梁策由此进入具有门禁、电表、公告、住户和长期生活痕迹的13栋。704住户刘桂兰确认自己是投诉人，并坚信楼上一直有804；现实建筑初始只有七层。02:00后楼梯结构逐渐变化，02:12二人进入新增八楼803/804。804公共区域长期积灰，一把木椅出现无人可见的位移，未知男性声音称现实中已退休两年的原工程主管陈德福“刚去拿钥匙”。屋内旧照片可复核“永安里居民区”和老式6栋入口，冲印时间为2015年。周衡因此披露自己长期记得童年住址“永安里6栋201”，但父母和常规现实资料一直否认这一住址。

中心历史资料随后出现可验证的不稳定：2015旧联动扫描`LJ-150907-0041`最初明确写“青梧苑13栋”，当前迁移数据库却缺该记录；04:23打印的完整旧页仍写13栋，同一电子源稍后重新打开变为12栋，04:30第二版打印也跟随变化，而第一版纸暂时保留13栋。门岗王启明又把此前亲手发现的旧钥匙自然说成“12屋面”，现场却在未提示情况下读出实体标签“13屋面”；其本人01:49聊天照片和04:44新照片都显示13屋面，但他不记得01:49拍摄行为。截至第60章，王启明仍是唯一达到“具体事件记忆与本人保留记录/当前实体直接冲突”标准的F008样本，不能扩大成普遍失忆规则。

704原工单在刘桂兰确认噪音已停后两次正常办结都恢复为处理中，无新热线时“最近诉求时间”仍刷新。Day 2 07:08，同一原工单当前投诉人变成周衡、地址变成永安里6栋201、最近诉求时间变为07:08，但原工单号、刘桂兰00:17热线录音和联系电话仍保留；没有周衡主动投诉记录。白班系统管理员只能确认07:08:11服务账号`svc_addr_route`执行过“未映射地址复核/责任路由重算”，地址来源ID为空且设计写回范围不含投诉人，因此只能视为技术触点，不能证明它生成了永安里6栋201或修改投诉人。这个字段变化把周衡的私人过去与职业工单正式绑定，但当前工单字段始终不能反向充当历史地址证明。

Day 2白天至第二夜班，周衡按手续追青梧苑历史纸档。2015物业回访、原维修单、中心外部流水、E-07《二期室外照明总平》、旧回访附件和中心夜联原册形成一条正常历史链：二期13#曾作为独立建筑存在，东侧公照箱③旧支路指向13#东梯，刘桂兰当时已被记录为二期13#704住户。陈德福看完整E-07后能以专业判断确认图中的13#是楼号，但其自然记忆仍只记得二期住宅7至12，无法可靠回忆自己是否进入13#或经办具体维修，因此不构成新的F008样本。

同一时期的地址维护链却是另一套结果。2015夜联原册明确写过“地址索引未检13栋 / 按原述转物业核址”；随后`DZFK-150907-06`正式反馈该缺项，维护侧因标准地址源没有对应新增楼栋、也没有正式新增/变更来源，决定不把13栋补入主表。更早的2015-08-31上游“临江市标准地址基础库”快照本身已经只列青梧苑1—12。于是青梧苑形成可追溯的业务层分叉：正常物业/工程/维修/回访/住户链保留13#，同期标准地址链却只承认1—12。原因未知，这一案例只能作为以后判断不同业务层可能分叉的方法参照，不能直接证明永安里与青梧苑属于同一异常机制。

第二张异常倾向工单来自62岁钱先生。他称黑色帆布包遗留在地铁末班车，自己仍在“二号线槐荫路终点站”等候。现实中该站2008年投入运营时名为槐荫路站且为终点，2012年延伸后不再为终点，2016年改名临江南。钱先生无提示报出旧B口永安里、槐荫路菜市场、已拆旧站务亭、旧尽端墙和旧式柱号等历史细节，并在现行列车进出时坚持自己所在站台没有列车。中心始终不让他进入轨行区、封闭通道或自行寻找出口，并建立固定短联络和失联/症状升级条件。

23:17一次固定联络的中心原录音保存了“终到槐荫路站”的旧清客广播，同分钟现行临江南有正常列车到发，但现行广播日志没有旧站名内容。历史文本`HY-QK-02`可与录音对应，旧扬声器B2-04的位置可落到现行仍保留的P17结构柱附近；P17北侧历史排水点D-17位置也在改造后保留。一次有限同步接应中，现行D-17旁放置黄色折叠警示牌且有值班员和普通乘客活动，而钱先生同期原录音仍称没有人和新增物。由于旧长椅具体视线、钱先生实际坐位和候选点是否就是同一实际位置均未证明，这些记录只能保存为多媒介观察差异，不能写成互相不可见、身处过去或双空间重合。

现实处置随后取得突破。前一运营日末班回库车辆的车辆段临时交接记录显示，Day 2 00:28二号车厢三连座下已发现一只黑色帆布包，00:36封签后转失物集中点。钱先生在不知道候选包细节时说出右侧提手根部灰线修补和身份证所在夹层，轨道方据实物与身份证确认包、证件和常用降压药均属本人。对应末班车辆车载视频又确认钱先生在前一运营日23:58从现行临江南站下车，黑包留在车上；最小站台视频把其最后可见路径锁到东段广告灯箱与包柱形成的视觉折角。Day 3 02:16，既定固定联络电话铃声被正在该区域搜索的现行站务人员听见，值班员绕入灯箱里侧后找到仍坐在候车椅上的钱先生；02:21完成现实接管，02:52由家属陪同离开。钱先生获救后仍坚持此前看到旧槐荫路环境和旧站务亭男性值班人员，但这些只作本人证词，不按证词追具体历史人员，也不升级为F008。

第三夜班继续沿2016槐荫路更名前改造档案调阅。连续影像第09张正面拍到B口蓝底公共导向牌“永安里”，项目拆改对象编号为`DX-B-06`。同项目资料确认它于2016-01-13拆除，次日随B口四件旧标识以交接单`BZ-YJ-160114-02`移交二号线运营物资周转库北库；北库自身到货账确认实收4件，2016-01-15分类表又以原项目编号把该对象登记为`BK-JBS-160114-03`。2019记录显示它转入运营资料样本间`S2-07`作历史标识留样/培训参考。当前只按分类号与架位提交实物核验，截至第60章仍待正常盘点；2019留样及当前未见后续出库/报废记录不能替代Day 7实物在架证明。

为了判断“永安里”究竟属于哪一层资料，三人从2011轨道旧B口导向图的编制依据反查到市级`GGDX-2010-11`公共导向底图。旧B口图幅存在`YD-073 / 永安里 / 居民地（沿用名） / 可用于公共导向`，2011轨道审核附件明确引用该点。数据字典同时明确：公共导向层可以使用历史沿用名或约定俗成居民地名，但不生成门楼牌编码、不替代标准地址基础库、不作为住户登记依据。同一历史图幅的可见标准地址快照当前未见名为“永安里”的标准地址对象，但这个阴性结果只限具体版本、图幅和当前可见范围，不能扩大成“历史上从未存在”。第二卷因此以“公共导向已证、正式地址未证、6栋201需独立来源”阶段收束。

第三卷从普通正式地址控制样本开始。老城区来电人用“花枝巷17号”报门牌坠落风险，现行标准地址却是同一院落“槐北路112号附1”。责任单位沿革卡确认旧号于2018-06-18按“东桥片区门楼牌调整通知2018年第27批”正式调整为新号；现场松动的是多年未拆的旧搪瓷牌，现行标准门牌正常。此后又以同批随机普通记录“纸坊巷8号→槐北路108号”验证索引路径，建立正常规则：居民旧称、旧实体牌、现行门牌和正式沿革文书可以同时存在，且未知来源文书时可按行政区片、历史图幅/旧道路范围和大致年代申请候选索引。

三人没有直接全文搜索“永安里”，而是依据2008旧终点、2010公共导向底图、2011轨道引用和2012线路延伸，将旧B口首轮门楼牌目录范围限定为2008—2012。目录筛到2010年第4批与2011年第2批，其中2010年第4批纸册117—146页连续，但数字化影像缺129页。2014数字化作业台账随后证明129页当时随原册在场，只因装订过紧、内侧栏遮挡导致首扫质检失败，失败影像作废不入正式库，纸页随册退回。2017整册移交链又证明该原卷转入东桥区旧城历史建设资料室，但这些历史节点都不能替代当前实物核验。

东桥区后续确认现行馆藏号`DQ-JS-2010-MLP-04`，117—146页当前在馆且页序连续，129页在册；2021曾做保护性利用采集，所以129页已有可读利用影像。129页的正式字段“历史登记片区”明确写“永安里”，调整类别为“旧城居住区整编转出”，门楼牌详项指向`DQLP-2010-04-B3`。这只证明永安里进入正式门楼牌沿革资料链，不等于“永安里6栋201已证”。

B3全名为《2010年第4批门楼牌整编迁出对象清册》。“迁出”在该业务中指门楼牌登记对象退出当前底册、转后续住址核对专卷，不等于居民搬走或户籍迁移。永安里对应B3-17，对象类别为“建筑门楼牌登记对象”、数量8项，承接索引为`DQ-DZHD-2010-17`；B3-17只是组号，8项也不能事先猜成8栋。随后真正开放的建筑地址对应表才把八项逐行展开为永安里1栋至8栋，因此**永安里6栋第一次获得独立的建筑层正式地址业务证明**。这张表仍没有201、单元或住户字段，所以完整“永安里6栋201”仍未获得独立历史链。

`DQ-DZHD-2010-17`的来源附件目录又出现`附核-04`：2010年10月“夜间联动地址核查抄件”，来源单位是当时的临江市夜间城市联动值班室，原始记录索引`夜联-2010-10-C`。2012机构调整后，这套旧夜联资料按年度并入现夜间综合服务中心历史档案保管；这只证明档案保管沿革和记录来源连续，不能把2010旧机构直接等同当前中心岗位体系。

`夜联-2010-10-C`原册42—43页随后开放。记录形成于2010-10-18 22:31—22:54乙班，事项为“永安里第17组部分建筑地址核对”。旧表把职责拆成来话来源、核查事项、记录席位、当班复核、转报对象、反馈记录、签收等栏：记录席位为C-3，当班复核为乙班值守负责人，22:39反馈写“已收核查范围，待回电”，22:51写“按当班核址反馈转报，具体对象以地址整理组后续底册为准”，签收方为东桥旧城门楼牌整理组。旧册利用说明明确：记录席位负责接收/登记/首次转报；反馈可由记录席位或接到回电的其他当班席位补录。因此C-3、复核角色、反馈补录者、实际核址人员和签收方不能自动合并成同一个人。

第60章再用与席位名册独立归档的综合行政排班/出勤记录做第二来源交叉。Day 7清晨核验确认：梁策列入2010-10-18乙班，出勤状态为到岗；当前可见范围未登记请假、代班或调班，且与席位名册人员信息一致。因此目前能够成立的结论只有两层：**梁策当晚确实实际在班；同日乙班席位名册把他映射为C-3记录联络席位。** “未登记请假/代班/调班”不能扩大成整晚绝无临时换席，两份记录也都不能证明22:51反馈由梁策接收或补录，更不能证明其实际参与现场/外部核址，或者就是M003所需的“最后一次相关夜间处置人员”。梁策本人也拒绝用十六年前模糊记忆补这一缺口，周衡因此确认证据规则至少没有在涉及梁策本人时失效，二人张力略有收束但没有消失。
