# 连续性 QA

每章进入 `chapters/ready/` 前逐项检查。

## 人物
- [ ] 人物所在地点与上一章结束状态可衔接。
- [ ] 伤势、疲劳、疾病没有无解释消失。
- [ ] 已获得/丢失/消耗的物品一致。
- [ ] 人物目标与近期经历一致，若改变有触发原因。
- [ ] 人际关系变化有剧情依据。

## 知识边界
- [ ] 每个角色只使用其已经知道、相信或合理推断出的信息。
- [ ] 秘密没有被无意提前泄露。
- [ ] 错误认知若被纠正，正文中存在明确触发事件。

## 世界与时间
- [ ] 世界硬规则未被便利性突破。
- [ ] 时间先后、昼夜、路程、等待时间合理。
- [ ] 地点关系和移动距离合理。
- [ ] 组织/制度反应与既定规则一致。

## 主线与伏笔
- [ ] 本章未提前破坏主线硬节点。
- [ ] 触及伏笔时已更新 `memory/foreshadowing.csv`。
- [ ] 回收伏笔与此前信息一致，不临时偷换设定。

## 章节价值
- [ ] 至少有一个有意义状态发生变化。
- [ ] 删除本章会明显损失剧情、人物、信息或气氛功能。

任一硬错误未解决时：`qa_status=fail`，不得进入 `ready/`。
