# 文风 QA

## 去模板化检查
- [ ] 没有大段复述上一章。
- [ ] 没有连续用心理解释重复已经由行动表达的情绪。
- [ ] 没有为了凑字数重复同一个事实。
- [ ] 没有大量“微微、缓缓、不由得、心中一动”等弱动作填充。
- [ ] 没有无剧情功能的万能环境描写。
- [ ] 没有用总结句替读者解释刚刚发生的场景意义。
- [ ] 章尾没有机械复用万能悬念句式。

## 人物声音
- [ ] 主要角色对话可区分。
- [ ] 人物允许沉默、误解、回避、打断，不人人都把意思说完整。
- [ ] 对话符合身份、关系和当下压力。

## 句段节奏
- [ ] 段落长度有自然变化。
- [ ] 高压场景减少说明，增加即时动作与选择。
- [ ] 过渡场景有信息、关系或决策价值。

## 精简测试
随机检查若干句：若删掉后人物、剧情、信息、氛围均不受损，应优先删除或合并。

## 长度
优先区间见 `config/novel.yaml`。超出优先区间不自动判错，但必须解释为什么剧情需要；严禁单纯补字。
