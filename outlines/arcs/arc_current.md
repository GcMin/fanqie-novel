# 当前剧情弧

## Arc ID
ARC-005：旧号新号

## 覆盖章节
预计第49—58章，作为第三卷前半段短弧。目标是建立正式地址“正常沿革”对照和可执行的历史门楼牌/建筑地址调查入口，只把调查推进到M003之前的准备位置，不提前锁定当年最后处置人员。

## 起始状态

Day 3约23:27。第二卷与ARC-004已经完成阶段收束。周衡、梁策、夏宁正在第三夜班继续正常值守。

当前已经确认：“永安里”在历史公共导向层真实存在过正常使用痕迹。2010市级公共导向底图`GGDX-2010-11`存在`YD-073 / 永安里 / 居民地（沿用名）`，2011轨道B口导向审核附件引用该点，2016改造影像又拍到实际悬挂的“永安里”导向牌。旧牌普通物资链已推进到`DX-B-06 → BZ-YJ-160114-02 → 北库实收 → BK-JBS-160114-03 → 2019 S2-07留样`，但Day 3当前实物仍待正常盘点。

第二卷同时固定了边界：公共导向不等于正式地址；同期目标图幅的标准地址快照阴性只能限于该版本/图幅/可见范围；704当前字段“周衡 / 永安里6栋201”不能反向证明历史正式地址。当前正式地址层只能写“未取得独立来源”。

## 主要矛盾

三人已经知道下一步应该从门楼牌编制、建筑地址登记、住户登记/迁入迁出等正式业务源进入，但他们尚未建立“正常正式地址变更到底会留下什么”的现实对照。如果直接拿“永安里6栋201”去搜，仍会重复第二卷早期那种把结果当检索条件的问题。

因此本弧先从一张真实夜间城市服务工单建立正常门牌沿革样本，再用正常字段和来源文书逐步进入历史地址资料。异常感不能靠数据库突然吐答案，而要来自普通流程与现有证据之间越来越难解释的缺口。

## 本弧目标

- 第49章先完成一张门楼牌松动/坠落风险的普通城市服务工单，通过同一院落的旧号/新号正常映射，建立正式地址变更的控制样本。
- 明确正常门牌沿革至少可以留下旧号、新号、生效时间、变更原因、来源文书和当前有效状态等字段；实体旧牌残留不能替代当前地址状态。
- 后续只按区片、历史图幅、变更批次、来源文号和沿革索引进入历史正式地址资料，不做无边界地名全文搜索。
- 允许出现数字化未完成、纸档移交、索引缺页或普通保管差异，并优先按正常档案问题处理。
- 在第58章前把正式地址调查推进到一个能与中心更早历史处置资料发生正常业务连接的入口，但不确认M003目标人员。
- 保持职业流：普通工单仍要按安全、责任、专业边界和回访闭环处理，不因主线调查降低现实服务质量。

## 建议章节节奏

### 第49章《掉下来的门牌》
接续23:27正在加载的普通工单。来电人使用老城区旧门牌称呼，但现行系统返回同一院落的新标准地址；现场核实是一块多年未拆的旧门牌松动，而现行门牌完好。通过责任单位的正常沿革记录建立一份完整旧号→新号对照，先把坠落风险处置闭环，再记录正常正式地址变更会留下哪些字段。

### 第50章《旧号新号》
只沿第49章正常样本的来源文书与沿革索引理解本市旧号/新号登记方式，并以同一片区另一份普通变更记录做交叉验证。形成后续历史检索规则，不碰永安里答案。

### 第51章《图幅索引》
按2010公共导向底图所在旧城图幅申请对应年代的门楼牌变更索引目录，只看区片/批次/来源范围。若未见“永安里”，保存有限阴性结果，不扩大结论。

### 第52章《缺的一页》
沿索引中的连续页序或移交说明定位一处资料缺口，先判断未数字化、移交、损毁、重新装订等普通原因；不得自动写成被删除。

### 第53章《白班回函》
取得保管部门的正式回函，确认目标年代部分门楼牌底册已转区级历史档案或旧城整编项目卷，获得下一层正常调阅入口。

### 第54章《大家都这么叫》
穿插一张老城区普通服务工单，展示居民长期口头地名与正式门牌可以并存甚至不一致，进一步压住“有人这么叫=正式地址”的偷换。

### 第55章《沿革底册》
按已取得的卷宗/批次入口查看目标区片正式地址沿革资料，先建立周边道路和门牌的正常连续样本；永安里即使出现也只按实际字段推进，不补缺失层级。

### 第56章《迁出批次》
从正式地址资料中的正常整编/迁出或建筑注销类来源进入居民生活史，但只确认批次与业务对象，不凭一个项目号直接认定永安里6栋201。

### 第57章《旧中心抄件》
历史地址处置资料中出现与当年夜间联动相关的抄件/转报编号，为夜间中心更早纸质处置史建立新入口；先追记录家族，不追具体人。

### 第58章《谁写的》
核当年抄件的值班字段、席位或签批方式，确认存在可追踪的人员记录结构，但身份仍需后续独立交叉，不在本弧提前完成M003。

## 本弧可推进伏笔

- **F003**：从公共导向层向正式地址沿革层推进，但第58章前不要求完成6栋201证明。
- **F007**：只有历史地址资料自然重新碰到旧物业/陈德福时才推进，禁止为了找人硬拉回。
- **F008**：默认不新增。普通居民使用旧称、记错门牌或习惯叫法不是具体事件记忆冲突。

## 本弧禁止事项

- 不把第49章正常门牌沿革样本直接套成永安里机制。
- 不以“永安里”或“永安里6栋201”无来源约束地全库搜索。
- 不把旧门牌实体残留写成当前正式地址仍有效。
- 不把历史资料缺页、未数字化、移交或找不到自动写成人为删除。
- 不按钱先生旧站务亭男性值班员证词追具体人员。
- 不提前确认M003目标人员，不解释完整失址机制、工单系统来源或周衡保留记忆原因。
- 不因第三卷进入正式地址线就暂停普通夜班职业任务。
